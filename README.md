# Projeto Teste — Software House (30 dias)

Este repositório contém um **projeto teste de 30 dias**, criado para validar parceria técnica, disciplina e capacidade de entrega.

Não é projeto de estudo nem hobby.

---

## 🎯 Objetivo
Desenvolver um **mini sistema de agendamentos com automação**, simulando um cliente real, com foco em:
- organização
- entrega semanal
- comunicação clara
- código funcional

Entrega > intenção.

---

## ⏱️ Duração
- Início: **09/02/2026**
- Fim: **08/03/2026**
- Entregas semanais obrigatórias
- Reunião 1x por semana

---

## 🧱 Stack definida
- Backend: Node.js + Express
- Frontend: HTML + CSS + JavaScript puro
- Banco de dados: SQLite
- Versionamento: GitHub
- Comunicação: Discord

## 🔀 Fluxo de trabalho (Git)

Repositório único

Branches:

main → protegida

thales → desenvolvimento Thales

guilherme → desenvolvimento Guilherme

Commits diretos na main são proibidos

Toda alteração entra via Pull Request


## 📝 Padrão de commit

Formato obrigatório:

tipo: descrição curta

### Exemplos:

feat: cria estrutura inicial do frontend

fix: corrige erro na listagem

chore: organiza arquivos

## 📦 Entregas

Toda entrega semanal deve ser:

versionada

funcional

registrada no Discord

Código que não roda = entrega inválida.

## ⚠️ Observações importantes

Este projeto existe para validar perfil de trabalho, não ego

Falta de entrega compromete a continuidade

Decisões técnicas devem ser documentadas
